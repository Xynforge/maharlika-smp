# MAHARLIKA SMP Website

## Edit these before publishing

1. Open `script.js`.
2. Change `YOUR-SERVER-IP-HERE` to your Minecraft server address.
3. Open `index.html`.
4. Replace `https://discord.com/` with your real Discord invite.
5. Add your real payment links to the five Points Store buttons.

## Points Store
- ₱50 → 250 Points
- ₱100 → 550 Points (+50)
- ₱200 → 1,200 Points (+200)
- ₱500 → 3,250 Points (+750)
- ₱1,000 → 7,000 Points (+2,000)

Playtime: 1 Point every 60 seconds.

## GitHub Pages
Create a GitHub repository, upload `index.html`, `style.css`, and `script.js`, then enable:
Settings → Pages → Deploy from a branch → main → / (root).
